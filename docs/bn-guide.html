টাইপিং গাইড

যেকোনো বাংলা শব্দ লিখুন।

macOS-এ অভ্র ফোনেটিক, প্রভাত ও ইউনিজয় দিয়ে প্রতিটি বর্ণ, চিহ্ন ও যুক্তাক্ষর। এই পাতার প্রতিটি উদাহরণ অ্যাপে মিলিয়ে দেখা।

উইন্ডোজের অভ্র কিবোর্ডের জন্য ওমিক্রনল্যাবের নির্দেশিকা, Bangla Typing with Avro Phonetic ও Bangla Typing with Fixed Keyboard Layouts অবলম্বনে, ম্যাকের জন্য লেখা।

শুরু করা

  1. মেনু বারের ইনপুট মেনু থেকে Avro Keyboard বেছে নিন, অথবা ইনপুট সোর্স বদলানোর শর্টকাট দিয়ে চালু করুন (ডিফল্টভাবে Control Space বা 🌐)।
  2. Preferences… › Keyboard Layout-এ একটি লেআউট বেছে নিন। অভ্র ফোনেটিক ডিফল্ট; এই অংশের বাকিটা তা নিয়ে, আর প্রভাত ও ইউনিজয় আছে পরে।
  3. লিখতে থাকুন। কোন কি কী দেয়, তা নিচের নিয়মগুলোতে আছে।

ক্যান্ডিডেট বার

উইন্ডোজে অভ্র যা লিখছেন তা একটি প্রিভিউ উইন্ডোতে দেখায়। ম্যাকে শব্দটি লেখার সময়ই আপনার লেখায় আন্ডারলাইন হয়ে দেখায়, আর তার নিচে থাকে ক্যান্ডিডেটের একটি বার:

  1. আপনার নিজের রিপ্লেসমেন্ট বা বিল্ট-ইন অটো-কারেক্ট এন্ট্রি, যদি থাকে
  2. আপনি যা টাইপ করেছেন, হুবহু, ইংরেজি শব্দ রাখার জন্য
  3. মিলে যাওয়া ডিকশনারির শব্দ, সবচেয়ে কাছের বানান আগে
  4. এই পাতার নিয়মে তৈরি সরাসরি বর্ণান্তর, আর মিলে যাওয়া ইমোজি

Space বা Return চাপলে বাছাই করা শব্দটি বসে। অ্যারো কি দিয়ে ক্যান্ডিডেটের মধ্যে যাওয়া যায়, আর 1–9 চেপে নম্বর দিয়ে বাছা যায়। Delete শেষ টাইপ করা অক্ষরটি মোছে।

শুধু নিয়মগুলো কীভাবে কাজ করে দেখতে চাইলে Preferences-এ Include Dictionary Suggestions বন্ধ করুন। তখন বারে শুধু বর্ণান্তর আর আপনি যা টাইপ করেছেন তা থাকে।

নিয়ম ৪: যুক্তাক্ষর

আলাদা কিছু শিখতে হয় না। পাশাপাশি লেখা ব্যঞ্জনবর্ণ বাংলায় যুক্তাক্ষর হলে অভ্র নিজেই তা জুড়ে দেয়:

okkhor → অক্ষরonto → অন্তbiggo → বিজ্ঞbrahmoN → ব্রাহ্মণlokkhmI → লক্ষ্মীsombol → সম্বল

নিচের পূর্ণ যুক্তাক্ষর তালিকায় প্রতিটি যুক্তাক্ষর আর তা লেখার নিয়ম আছে।

ব্যঞ্জনবর্ণ আলাদা রাখা

কখনো জোড়া লাগতে পারে এমন দুটি ব্যঞ্জনবর্ণ আলাদা রাখতে হয়। কান্তা ও কিন্তু-তে ন আর ত জোড়া লাগে, কিন্তু কিনতে-তে নয়। দুটি বর্ণের মাঝে ব্যাকটিক ` দিলে তারা আলাদা থাকে:

জোড়া লাগা দরকারভুল করে জোড়া লেগেছে` দিয়ে আলাদা
গ্লglOb → গ্লোবaglanO → আগ্লানোag`lanO → আগলানো
ক্টokTOpas → অক্টোপাসekTa → এক্টাek`Ta → একটা
ম্রmriyomaN → ম্রিয়মাণamra → আম্রাam`ra → আমরা

এটি কমই দরকার হয়। ডিকশনারি সাজেশন চালু থাকলে ক্যান্ডিডেট বার সাধারণত ঠিক শব্দটিই দেখায়: amra লিখলে আমরা আগে আসে, আর ekta বিল্ট-ইন অটো-কারেক্ট থেকে একটা দেয়।

অভ্র ফোনেটিকে ক্ম-এর কোনো নিয়ম নেই। ডিকশনারি থেকে এমন শব্দ বেছে নিন, যেমন rukmini → রুক্মিণী, অথবা নিজের রিপ্লেসমেন্ট হিসেবে যোগ করুন।

অটো-কারেক্ট

কিছু শব্দ নিয়ম মানে না: বাংলায় লেখা ইংরেজি শব্দ, নাম, আর যেসব বানান নিয়মে ভুল আসে। অটো-কারেক্ট এগুলো সামলায়, আর এর এন্ট্রি ক্যান্ডিডেট বারে সবার আগে আসে।

বিল্ট-ইন: অভ্রের সঙ্গে প্রায় ১০,০০০ এন্ট্রি আসে, যেমন sir → স্যার, software → সফটওয়্যার আর brb → একটু পরে আসছি। এগুলো Preferences… › AutoCorrect › Built-in-এ দেখা যায়, আর ডিকশনারি সাজেশন চালু থাকলে আসে।

আপনার নিজের: Preferences… › AutoCorrect › Personal-এ এন্ট্রি যোগ করুন। + চাপুন, শর্টকাট লিখে Return চাপুন, তারপর লিখুন এটি কী হবে। এগুলো সবার আগে আসে, ডিকশনারি সাজেশন বন্ধ থাকলেও। কয়েকটি ব্যবহার:

  • নিয়মে ভুল আসা শব্দ ঠিক করা। amra → আম্রা ম আর র জুড়ে ম্র বানায়। amra → আমরা যোগ করলে সব সময় ঠিক আসবে।
  • ইংরেজি বানানে বাংলা শব্দ। zoom দিয়ে জুম পান, যেমন software → সফটওয়্যার আগে থেকেই আছে।
  • ছোট শব্দে লম্বা লেখা। enam দিয়ে পুরো নাম, enamul hok cOUdhurI → এনামুল হক চৌধুরী, বা brb দিয়ে পুরো একটি বাক্য।
