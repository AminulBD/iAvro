01 — Features

The layout you know, built for the Mac.

The Avro phonetic layout from Windows and Linux, as a proper macOS input source.

01

Avro phonetic layout

The same transliteration rules as the original Avro Keyboard, so your muscle memory carries over. Probhat and Unijoy are built in too.

02

Candidate window

Alternate spellings appear as you type; pick one with the arrow keys. Horizontal or vertical panel.

03

Dictionary suggestions

Optional dictionary lookups show real words alongside the phonetic candidates.

04

Auto-correct and auto-dictionary

Corrections for common slips, plus a personal dictionary that remembers what you pick.

05

Native Swift

Rewritten on Apple's Input Method Kit. No CocoaPods, no bundled libraries; SQLite comes from the system.

06

Universal builds

CI produces Apple Silicon, Intel and universal binaries for every release, signed and notarized when certificates are configured.

Three keyboard layouts

Type phonetically, or use the fixed layout you already know. Switch any time under Preferences… → Keyboard Layout.

PHONETIC

Avro Phonetic

Write Bangla in Latin letters the way it sounds: ami becomes আমি.

The default. Candidates, dictionary suggestions and auto-correct work with this layout.

FIXED

Probhat

Every key types a Bengali letter directly: k ক, v আ, / hasanta.

The same key map as Probhat in Avro Keyboard for Windows.

FIXED

Unijoy

The Bijoy-style layout: j ক, f া, g hasanta.

g before a vowel sign makes the full vowel: g f → আ. Press g twice for a visible hasanta.

With the fixed layouts, type in Unicode order, with a vowel sign after its consonant (কি is ক then ি). Key positions follow a US keyboard, and the Option-key layer isn't included yet.

03 — Install

About a minute, either way.

Use Homebrew, or download the DMG and double-click.

With Homebrew

Terminalzsh
$ brew install --cask aminulbd/tap/avro

Installs the app into ~/Library/Input Methods. Update later with brew upgrade --cask avro, remove with brew uninstall --cask avro. Then switch to it from the input menu in the menu bar.

Manually

  1. Download the DMGGet Avro-Keyboard-universal.dmg from the latest release. There are also apple-silicon and intel builds if you prefer a smaller one.
  2. Open it and click InstallOpen the DMG and double-click Avro Keyboard. It copies itself into ~/Library/Input Methods (for your user only) and adds itself to your input sources.
  3. Start typingSwitch to it from the input menu in the menu bar, or with ⌃ Space.
Not in the input menu? Log out and back in, then open System Settings → Keyboard → Input Sources → Edit… → +, choose Bangla → Avro Keyboard, and click Add.
Had the old iAvro installed? Remove it first, or two Avro Keyboard entries appear in the input menu. Remove it from System Settings → Keyboard → Input Sources → Edit…, delete Avro Keyboard.app from ~/Library/Input Methods or /Library/Input Methods (in Finder press ⌘ ⇧ G and paste the path), then log out and back in before installing.
Upgrading? Open the new DMG and double-click the app again; it replaces the installed copy. Log out and back in afterwards. Preferences and your personal dictionary are kept.
04 — Build

Build from source.

Requires Xcode 16 or later. No external dependencies.

Open AvroKeyboard.xcodeproj in Xcode and build the Avro Keyboard scheme, or use the command line.

The built app lands at build/Build/Products/Release/Avro Keyboard.app.

Bundle identifier: app.aminul.inputmethod.AvroKeyboard

Terminalxcodebuild
$ git clone https://github.com/AminulBD/iAvro.git
$ cd iAvro

$ xcodebuild -project AvroKeyboard.xcodeproj \
    -scheme "Avro Keyboard" \
    -configuration Release \
    -derivedDataPath build
